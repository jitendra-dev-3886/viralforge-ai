# viralforge-ai
An AI-powered content automation platform that helps creators, marketers, agencies, and businesses generate high-quality content in seconds.

## Features

- ✍️ AI Writer
- 📝 SEO Article Generator
- 🖼️ AI Image Generation
- 📱 Social Media Content Generator
- 💡 Blog Generator
- 📄 Smart Content Templates
- 📚 Content History
- 👤 User Authentication
- 💳 Subscription & Billing
- ⚡ FastAPI REST APIs
- ⚛️ React + Vite Frontend
- 🎨 Tailwind CSS UI

## Tech Stack
### Backend
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL / MySQL
- JWT Authentication

### Frontend
- React
- Vite
- Tailwind CSS
- React Router
- Axios
